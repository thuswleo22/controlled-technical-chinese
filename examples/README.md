# 导出故障日志

这里使用项目原创示例。假设原始业务要求规定工单始终有效，且值班员有权导出或审计员已批准，两者满足其一即可。值班员负责保存导出记录。

运行检查器时，改写前的文件触发三条诊断。它们分别对应混合条件、步骤缺少执行者和悬空指代。改写后由括号表达原始授权要求，由步骤字段表达责任人和保存对象。实际业务中需要先查证这些事实，再写入改稿。

| 文件 | 预期诊断 |
| --- | --- |
| [改写前](before.md) | LOG-01、REF-01、REF-02。 |
| [正确改写](after.md) | 无。 |
| [错误分组](wrong-grouping.md) | 无。 |

当值班员有权限、审计员未批准、工单无效时，正确改写禁止导出，错误分组允许导出。应按工单始终有效这一业务约束选择正确分组。用这一组输入核对改写，可以发现形式检查未报告的错误。
