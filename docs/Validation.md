# 验证与证据范围

在仓库根目录运行。需要 Python 3.9 或更新版本及 OpenSSL 命令行。程序使用本地夹具，复跑过程无需下载语料或模型。

```sh
python3 experiments/reproduce_public.py
```

| 验证对象 | 发布的证据 |
| --- | --- |
| 检查器 | 57 个单元测试，包含规则触发、边界和退出状态。 |
| 规范 | 9 条编号规则的正反例和规范正文。生成的词典表与 166 条复审记录一致。 |
| 条件 | 432 个两类连接词组合和 972 个含异或组合。独立计算真值表，比较预期诊断与实际诊断。 |
| 新增规则与区间 | 27 个生成样本、128 个区间组合。用有理数集合独立判定区间。 |
| 工程词义 | 7 个操作见证，包括 SQLite 操作、OpenSSL 签名验证和字节前缀。 |
| 改写工作流 | 3 条诊断的原稿、0 条诊断的改稿、同为 0 条诊断但改变了授权含义的改稿。 |

复现程序会重新运行报告生成器，将 JSON 与 [已提交的报告](../results/)逐项比较，并检查示例的诊断和退出码。真值试验限制在指定的算子、写法和原子项数。操作见证验证给定操作的意义。真实句子的词义、角色及业务条件仍按上下文核对。

## 公开复算与研发记录

发布包包含项目原创规范、程序、合成夹具、词表复审及可直接复跑的报告。规范里的研发记录描述历史对照的范围和结果。其中真实文档段落、改编对照、逐例外部语境标注及相应全量报告保留在研发记录中。公开复跑以随仓库提供的内容为准。外部文档可以按[来源说明](Sources.md)从上游固定版本采集。

样本级结果用于说明规则在指定输入中的行为。对真实机构文档的误报、漏报和编辑效果，要用来自该场景的新文档和独立标签验证。
